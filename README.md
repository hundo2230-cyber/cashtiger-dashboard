# CashTiger 계기판

거시 지표와 섹터 대장주 밸류에이션을 한 화면에서 보는 계기판입니다.
**매일 아침 자동으로 갱신됩니다.**

👉 **[계기판 열기](https://hundo2230-cyber.github.io/cashtiger-dashboard/)**

---

## 이 저장소에 있는 것

발행된 화면(`.html` · `.css` · `.js`)**만** 있습니다. 숫자를 만드는 코드와 자료는 비공개
저장소에 있고, 이곳에는 자동화가 **허용된 확장자만** 올립니다(그 밖의 것이 섞이면 발행이
멈춥니다).

## 숫자의 출처

- 거시 지표 — [FRED](https://fred.stlouisfed.org/) (세인트루이스 연준)
- 기업 재무 — [DART](https://dart.fss.or.kr/) (한국) · [SEC EDGAR](https://www.sec.gov/edgar) (미국)
- 주가 — FinanceDataReader

## ⚠️ 투자 권유가 아닙니다

여기 있는 적정가·밴드·국면은 **공개 자료로 계산한 참고값**입니다. 가정값이 바뀌면 결과도
바뀝니다. 매매 판단의 근거로 쓰지 마세요.
